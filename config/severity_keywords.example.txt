# cyber_brief severity keywords: EXAMPLE / TEMPLATE
# ---------------------------------------------------------------------------
# HOW TO USE THIS FILE
#   1. Copy it to a new file named  severity_keywords.txt  (same folder).
#   2. Edit your copy: add the software you use to [watch1], and add, remove or
#      move any terms you like. Keep this example file as the original.
#
# One term per line. Lines starting with # are notes.
# Section names are in [square brackets]. Terms are checked against each
# story's headline and summary.
#
# THE THREE LEVELS
#   tier 1 = SEVERE   : rare. Extreme alarms, or something important that
#                       touches software you use (see [rules]).
#   tier 2 = NOTABLE  : broad net, "worth a look". Anything that might matter.
#   usual             : business as usual.
#   A digest is as severe as its most severe story.
#
# HOW TERMS MATCH
#   - Not case sensitive. "zero-day", "zero day" and "Zero_Day" are the same.
#   - A plain term matches at the start of a word and may keep going:
#       exploit      also matches exploited, exploiting, exploitation
#   - =term  matches the whole word only. Use it for short terms that would
#     otherwise match inside other words:   =RCE   =RAT   =APT   =SSN
#   - re:pattern  is a regular expression, for things like CVE numbers.
#
# WHICH LIST DOES WHAT
#   [tier1]   extreme alarms. One hit is enough.
#   [tier2]   important words. Broad on purpose.
#   [tier3]   weak words. Alone they do nothing.
#   [watch1]  software you depend on (fill this in with YOUR software).
#   [watch2]  popular software worth a look (Firefox, Chrome, and others).
#   [change]  admin-change words (retire, enforce, end of support).
#
# The [rules] section at the bottom says how the lists combine.
# ---------------------------------------------------------------------------
